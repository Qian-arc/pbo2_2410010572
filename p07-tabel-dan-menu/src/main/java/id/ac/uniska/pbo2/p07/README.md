# Mini Proyek: Katalog Buku Perpustakaan

Aplikasi desktop Java Swing untuk mengelola data katalog buku perpustakaan, dibangun menggunakan arsitektur tabel kustom (`AbstractTableModel`), pustaka tampilan FlatLaf, serta `JDialog` modal.

## Fitur Utama Aplikasi
1. **Tambah Buku**: Menambahkan data buku baru (Judul, Penulis, Penerbit, Tahun, dan Kategori) dilengkapi validasi input yang ketat.
2. **Ubah Buku**: Mengubah data buku yang sudah ada berdasarkan baris yang dipilih pada tabel.
3. **Hapus Buku**: Menghapus data buku dengan fitur konfirmasi dialog keamanan.
4. **Pencarian Real-Time**: Menyaring data buku secara dinamis menggunakan `TableRowSorter` dan `RowFilter`.
5. **Navigasi Menu & Pintasan**: Dilengkapi bilah menu (*Menu Bar*) serta pintasan papan ketik (`Ctrl+N`, `Ctrl+E`, `Ctrl+D`).
